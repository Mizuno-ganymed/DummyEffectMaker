# Dummy Effect Maker

Autodesk Maya でダミーエフェクトを作るための小さなツール群と、それらを起動するランチャーウインドウ。
まずは Maya 上の Python スクリプトとして作り、最終的にはスタンドアロン動作を目指す。

対応: Maya 2022 以降 (Python 3 / PySide2・PySide6 両対応)

## 起動方法 (Maya)

1. このリポジトリを任意の場所に置く
2. `scripts/maya_launcher.py` の `REPO_PATH` を置いた場所に書き換える
3. その内容を Maya のスクリプトエディタ (Python タブ) で実行する
   (シェルフにドラッグしてボタン化しておくと便利)

ランチャーのメニュー「開発 → ツールを再読み込み」で、コードを編集した内容を Maya を再起動せずに反映できる。

## 使い方

- 上部のタブで「ツール」「カメラ」「エネルギー弾」「衝撃波」「お化けブラー」「天候」「爆発」「布」を切り替える
- ウインドウ上部のメニュー「シーン」に、ベイク・全削除・環境設定 (プリセットの保存先) がある
- ツール名のボタン: 現在のオプション値ですぐに実行
- `□` ボタン: オプションダイアログを開く (適用 = 保存して実行 / 保存 = 値だけ保存)
- 1 回の実行は 1 回の Ctrl+Z で元に戻せる
- 下部のログ欄に実行結果やエラーが表示される

### アトリビュートエディタ (ランチャーの右側)

選んでいるエフェクト (ルートか、その中の弾・ロケータ・範囲の箱など) のパラメータを、日本語の名前と種類に合った入力欄
(数値・色・選択肢・チェック) で並べる専用のエディタ。メニュー「表示 → アトリビュートエディタ」で出し入れできる。

- **すぐ反映**の項目は、変えるとその場でアトリビュートが変わる (1 回の Ctrl+Z で戻る)。
  チャンネルボックスなどほかで変えた値も、表示に出る
- 「**(更新)**」の項目 (青い名前。数など) は、変えたら下の「〜を更新」ボタンで作り直す (動かす物やキーはそのまま)
- 右の **◆** でキーを打つ / 消す。色で状態が分かる: 赤 = このフレームにキー、桃 = キーあり (ほかのフレーム)、
  黄 = エクスプレッションなどで決まっている (変えられない)
- 「動かす物・つながり」のボタンで、範囲の箱・出る場所・爆心・ロケータや、つながったカメラ・風・弾を選べる。
  「ルートを選択」でルートに戻る
- **ロック**: 右上の「🔓 ロック」を押すと、選択を外したり別の物を選んだりしても、そのエフェクトを表示し続ける
  (カメラやロケータを動かしながらパラメータを調整する時に)。ロック中はパネルが**黄色い枠**で囲まれ、
  ボタンが黄色の「🔒 ロック中」になる。もう一度押すと外れて選択に付いてくる。ロックしたエフェクトを消すと自動で外れる
- 複数選んでいる時は最初の 1 つを表示する。ベイク済みのエフェクトは変えられない (その旨を表示)
- Maya の中でだけ使える (選択の変化・フレームの移動・アンドゥに付いてくる)

## ツール一覧

### 射撃 / 追尾弾

ロケータ A (発射位置) から B (経由点) を通って C (着弾点) まで、弾を指定フレームごとに撃ち続ける。

1. 「追尾弾」を押す。選択は不要
2. ルート `dfx_homingN` の子にロケータ `dfx_homingN_locA` (発射位置) / `locB` (経由点) / `locC` (着弾点) と弾がまとめて作られ、
   パラメータもルートのアトリビュートに設定済みになる
3. ロケータを好きな位置に動かす (弾道が追従する)。パラメータはルートのチャンネルボックスで調整する

```
dfx_homing1          ← パラメータ (チャンネルボックス)
  dfx_homing1_locA   ← 発射位置
  dfx_homing1_locB   ← 経由点
  dfx_homing1_locC   ← 着弾点
  dfx_homing1_path / _bulletSrc / _bullets
```

| オプション | 内容 |
| --- | --- |
| A〜C の距離 / B の高さ | 作成時のロケータの配置 (A は原点、C は X 方向)。作成後はロケータを直接動かす |
| 軌道 | なめらか: B を通る曲線 / 折れ線: A-B-C を直線で結ぶ |
| 発射開始 / 終了フレーム | この範囲で撃ち続ける |
| 発射間隔 | 何フレームごとに 1 発撃つか (小数可。0.5 なら 1 フレームに 2 発) |
| 着弾までのフレーム数 | 1 発が A から C に到達するまでの時間 |
| 減速 | なし (等速) / リニア / 2乗。着弾までのフレーム数は変えずに途中の速さを変える。リニア: 一定の割合で減速 (速さ = 1 − (1 − 最低) × t)。2乗: 最初に大きく減速し、だんだん緩やかに (速さ = 最低 + (1 − 最低) × (1 − t)²)。t は発射 0 〜 着弾 1 |
| 最低速度 (%) | 着弾時の速さ。発射時の速さに対する割合 (100% なら等速、0% なら着弾時に止まる速さ) |
| 弾の形状 | 球体 / つぶれた球体 |
| 伸び率 | つぶれた球体の時のみ。パスに沿った向き (進行方向) の長さの倍率。1 より大きいとパスに沿って伸び、1 未満だと平たくなる |
| インスタンスで作成 | ON なら全弾が元メッシュ (`*_bulletSrc`) のインスタンス。元メッシュを編集すると全弾に反映 |

- 軌道カーブはロケータに**ライブ接続**されているので、作成後にロケータを動かすと弾道も追従する
- 弾は発射フレームに出現し、C に到達したフレームの次のフレームで消える (visibility のステップキー)
- 弾は進行方向を向く (モーションパスの follow。X 軸 = 進行方向)

#### 作成後の調整

作成したルート `dfx_homingN` を選択すると、チャンネルボックスに全パラメータが並ぶ。

- **すぐ反映される**: 色・弾の半径・弾の形状・伸び率・球の分割数。
  キーも打てるので、半径などをアニメーションさせることもできる
- **「(更新)」が付いているもの**: 発射開始 / 終了フレーム・発射間隔・着弾までのフレーム数・減速・最低速度・軌道・インスタンスで作成。
  値を変えたあと、ルート (またはその中の弾) を選択して「追尾弾を更新」を押すと、同じ名前・同じロケータのまま作り直される。
  複数選択でまとめて更新でき、Ctrl+Z 1 回で更新前に戻せる
- ロケータは接続で覚えているので名前を変えてもよいが、削除すると更新できない (Ctrl+Z でロケータを戻せば更新できる)
- 「ダミーエフェクトを全削除」ではロケータも一緒に消える
- この機能より前に作った追尾弾 (旧名「バルカン砲」で作ったものを含む) にはアトリビュートが無いので、作り直しが必要

#### パラメータの保存と読み込み (プリセット)

- **追尾弾のパラメータを保存**: 追尾弾を 1 つ選択して押すと、ルートのアトリビュートの値を `.json` ファイルに保存する
- **追尾弾のパラメータを読み込み**: 追尾弾を選択して (複数可) 押し、`.json` を選ぶと、その値を設定して作り直す。
  ロケータの位置はそのまま。Ctrl+Z 1 回で読み込み前に戻せる
- 既定の保存先は「シーン → 環境設定」で変えられる。空欄なら `マイドキュメント/maya/DummyEffectMaker/presets/homing/`
  (ダイアログで別の場所も選べる)。
  ファイルを共有フォルダに置けばチームで使い回せる
- キーを打ってあるアトリビュートは読み込みで変更しない (ログに表示される)
- 保存されるのはチャンネルボックスのパラメータだけ (ロケータの位置は含まない)

### 射撃 / バルカン砲

発射位置から目標へ、まっすぐ飛ぶ弾を指定フレームごとに撃ち続ける。

**追尾弾との違い**: 追尾弾は飛んでいる最中の弾もロケータに合わせて軌道が変わる。
バルカン砲の弾は**発射したフレームでのロケータの位置**へ飛ぶので、発射後にロケータが動いても、
その弾の軌道は変わらない。ロケータにキーを打って動かすと、発射のたびにその時の位置から、その時の位置へ撃つ。

1. 「バルカン砲」を押す。選択は不要
2. ルート `dfx_vulcanN` の子に、発射位置 `_muzzle` と目標 `_target` (赤) のロケータ、弾がまとめて作られる
3. ロケータを動かす (キーを打つ)。パラメータはルートのチャンネルボックスで調整する

```
dfx_vulcan1            ← パラメータ (チャンネルボックス)
  dfx_vulcan1_muzzle   ← 発射位置
  dfx_vulcan1_target   ← 目標
  dfx_vulcan1_bulletSrc / _bullets
```

| オプション | 内容 | 反映 |
| --- | --- | --- |
| 発射位置〜目標の距離 | 作成時のロケータの配置 (発射位置は原点、目標は X 方向) | 作成時のみ |
| 着弾までのフレーム数 / 減速 / 最低速度 | 1 発が目標に届くまでの時間と、途中の速さ (追尾弾と同じ) | すぐ |
| 弾の形状 / 半径 / 伸び率 / 分割数 / 色 | 追尾弾と同じ。弾は進行方向を向くので、つぶれた球体は進行方向に伸びる | すぐ |
| 発射開始 / 終了フレーム / 発射間隔 / インスタンスで作成 | 弾の数が変わるもの | 「バルカン砲を更新」 |

- 既定値は連射向け (1 フレーム間隔、着弾まで 6 フレーム、つぶれた球体 × 伸び率 4)
- 弾は発射フレームに出現し、目標に届いた次のフレームで消える (追尾弾と同じ)
- 弾はエクスプレッションで動き、発射フレームのロケータの位置を `getAttr -time` で読む。
  ロケータは UUID で探すので、名前を変えたり、キャラクターの銃などの子にしたりしてもよい (ワールド位置を使う)
- 「バルカン砲のパラメータを保存 / 読み込み」は追尾弾と同じ (既定の保存先は `presets/vulcan/`)
- ベイクすると毎フレームのキーになり、エクスプレッションは消える

### カメラ タブ / 集中線

カメラに張り付き、画面の端から**中心の円**へ向かう集中線を作る。

1. カメラを選択して「集中線」を押す (未選択ならアクティブなビューのカメラ)
2. `dfx_focusLinesN` ができ、カメラにコンストレイントで張り付く。カメラを動かしてもズームしても画面上の線は動かない
3. 黄色い円 `dfx_focusLinesN_focus` を動かす・拡大縮小して、線の向かう位置と空ける大きさを決める
4. 長さ・太さ・色などはルートのチャンネルボックスで調整する

#### 中心の円

- 線は円の中心へ向かって並び、**円の中には入らない** (線の長さ 1 でちょうど円の縁に届く)
- 円は画面に平行で、移動 X / Y と拡大縮小 X / Y だけ動かせる (X と Y を別々に拡大すると楕円になる)。
  単位は「画面の横幅の半分 = 1」(画面の中心が 0、右端が X = 1)
- **円にキーを打てば、線の向かう位置・空ける大きさをアニメーションできる** (線は毎フレーム円に合わせて計算される)
- 「集中線を更新」しても円は位置・大きさ・キーごと残る。名前を変えてもよい
- 円が画面の端にかかる方向は線が出ない (長さ 0)。円を画面の外に出すと、画面の外の円へ向かう線になる
- 円はレンダリングされない (NURBS カーブ)。ベイク後は円を動かしても線は変わらない

#### 線の作り

1 本の線は 3 つのインスタンスでできている (どれもエクスプレッションで動く)。

- `_line_NNN` 本体: 画面の端から先端まで。長さに合わせて伸び縮みする
- `_tail_NNN` 延長: 画面の端から外へ一定の長さ (画面の外への延長)。
  本体の長さとは関係なく外まで届くので、伸び始めの短い線でも平らな根元が画面の中に見えない
- `_tip_NNN` 丸い先端: 先端の形が「丸い」の時だけ表示。本体とは別の円なので、縦横の倍率が違っても潰れない。
  丸い時も、線の先の位置 (円の縁までの長さ) はとがる時と同じ

| オプション | 内容 | 反映 |
| --- | --- | --- |
| 中心の円の大きさ | 作成時の円の半径 (既定 0.3)。作成後は円を直接拡大縮小する | 作成時のみ |
| 線の長さ | 画面の端から円へ向かって伸びる長さ。1 で円の縁に届く (方向ごとの「画面の端〜円の縁」の距離に対する割合。既定 1) | すぐ |
| 線の太さ | 画面の端での太さ (画面の横幅の半分 = 1)。先端に向かって細くなる | すぐ |
| 先端の形 | とがる (先端が点) / 丸い (先端を丸める) | すぐ |
| 先端の太さ (丸い時) | 丸い時の先端の太さ。画面の端での太さに対する割合 (既定 0.5。1 なら同じ太さのまま丸く終わる) | すぐ |
| 画面の外への延長 | 線の根元を画面の端から外へ延ばす長さ (既定 0.5)。根元が画面の中に見える時は大きくする | すぐ |
| 色 / 不透明度 | 線の色と不透明度 (ライティングの影響を受けない) | すぐ |
| カメラからの距離 | 線を置く位置。物体より手前になるよう小さめに (ニアクリップより大きく) | すぐ |
| 本数 / 長さのばらつき / 太さのばらつき / 乱数シード | 線の並び | 「集中線を更新」 |
| 動き | 静止 / ちらつき / **伸びて移動** (既定)。動きは作成・更新した時点のタイムスライダーの範囲にキーを打つ | 「集中線を更新」 |
| 伸びるフレーム数 | 伸びて移動の時: 1 本が画面の端から伸びきるまでのフレーム数 (既定 6) | 「集中線を更新」 |
| ちらつき間隔 (フレーム) | ちらつきの時: 何フレームごとに各線の長さが変わるか | 「集中線を更新」 |

- **伸びて移動**: 各線は画面の端から円へ向かって伸び、伸びきったら次のフレームで別の場所に移ってまた伸びる。
  移る先は直前の場所から 30° 以上離すので、続けて同じ場所から出ることはない。
  移る先はランダムな候補の中から「今出ているほかの線から一番離れた場所」を選ぶので、線は画面全体に均等に散らばる
  (空いている所から優先的に出る)。伸び始めのタイミングも均等にずらしてあり、毎フレーム同じくらいの本数
  (本数 ÷ 伸びるフレーム数) が移動し、全部が同時に移動することはない
- タイムスライダーの範囲を変えたら「集中線を更新」を押す

- 画面の大きさはカメラの焦点距離・水平フィルムアパーチャとレンダー解像度の縦横比から計算する (フィルムゲートは「水平」合わせ前提)。
  どれを変えてもすぐ反映される
- カメラの子にはしていない (Maya Software ではレンダーカメラの子がレンダリングされないため)
- 「ベイク」「ダミーエフェクトを全削除」にも対応

### カメラ タブ / スピードライン

カメラの前を、線が速いスピードで横切っていく。中央の四角の上辺より上と下辺より下に線が出て、左から右へ流れる。

1. カメラを選択して「スピードライン」を押す (未選択ならアクティブなビューのカメラ)
2. `dfx_speedLinesN` ができ、集中線と同じくカメラに張り付く
3. 黄色い四角 `dfx_speedLinesN_band` を動かす・回転・拡大縮小して、線を空ける帯と流れる向きを決める
4. 速さ・太さなどはルートのチャンネルボックスで調整する

#### 中央の四角

- 線は四角の上辺より上と下辺より下だけに出る (上辺・下辺を左右に延ばした帯の中には入らない)。
  帯の幅は四角の拡大縮小 Y で変わる (拡大縮小 X は見た目だけ)
- 線は四角の X 方向に流れる。**四角を Z 回転させると向きが変わる** (90° で下 → 上、45° で左下 → 右上、180° で右 → 左)
- **四角を X / Y 回転させると、線が奥行き方向に傾いてパースが付く** (下の「奥行きの傾き」)
- 移動 X / Y・回転 X / Y / Z・拡大縮小 X / Y にキーを打てば、流れる向き・傾き・帯をアニメーションできる
- 「スピードラインを更新」しても四角は位置・回転・大きさ・キーごと残る。四角はレンダリングされない
- 線は四角から見た「画面の範囲」の中だけに出る (四角をどこに置いても・回転・傾けても、画面全体に散らばる)

#### 奥行きの傾き (パース)

線は四角と同じ面の上を流れるので、四角を奥行き方向に傾けると線も傾き、カメラのパースが付く。

- **回転 Y**: 流れる先 (右側) が奥へ遠ざかる (マイナスなら手前に来る)。線は流れる先ですぼまり、奥の線ほど細く・短く見える
  (道路の先へ吸い込まれるような線)
- **回転 X**: 上側 (または下側) が奥へ遠ざかる。上下で線の太さ・間隔が変わる
- 傾けても、線は画面の範囲 (画面の 4 隅を通る視線と面の交点) の中を流れるので、画面全体に出る。
  画面を横切るのにかかるフレーム数も傾ける前と同じ
- 地平線が見えるほど傾けた場合は、カメラから画面までの 30 倍の距離までに線を出す
- 傾きは本物の 3D なので、ベイクしても FBX でもそのまま

| オプション | 内容 | 反映 |
| --- | --- | --- |
| 四角の幅 / 四角の高さ | 作成時の四角の大きさ (画面の横幅 = 2)。作成後は四角を直接拡大縮小する | 作成時のみ |
| 速さ | 1 フレームに進む距離 (画面の横幅の半分 = 1)。0.3 なら約 7 フレームで画面を横切る | すぐ |
| 線の長さ / 長さのばらつき | 線の長さ (画面の横幅の半分 = 1) と、そのばらつき | すぐ |
| 線の入りの太さ | 線の後ろの端 (流れてくる側と反対) の太さ (既定 0) | すぐ |
| 線の中の太さ | 線の真ん中の太さ (既定 0.012) | すぐ |
| 線の終わりの太さ | 線の先頭の端 (進んでいく側) の太さ (既定 0.002) | すぐ |
| 色 / 不透明度 / カメラからの距離 | 集中線と同じ | すぐ |
| 本数 / 速さのばらつき / 太さのばらつき / 乱数シード | 線の並び | 「スピードラインを更新」 |

- 太さは画面の横幅の半分 = 1 の単位。入り・中・終わりの 3 つを通るなめらかな曲線になる
- 線はキーを打たず、エクスプレッションで毎フレーム計算する。タイムスライダーの範囲に関係なく流れ続け、
  速さなどを変えてもすぐ反映される。画面を通り過ぎた線は、別の高さ・上下・長さで入り直す
- 速さにキーを打つと、変わった瞬間に線が飛ぶ (位置 = 速さ × フレーム で計算しているため)
- 「ベイク」「ダミーエフェクトを全削除」にも対応
- 大きく傾けると、画面の奥側の視線はとても遠くで面に当たるので、線が流れる範囲が奥へ大きく伸びる
  (Y 60° で画面 18 個分ほど)。「**奥の届く距離**」(既定 4。画面の横幅の半分 = 1) で、範囲を四角からその距離までに
  打ち切る (線が遠くまで散らばって、線の集まりの中心が四角からずれて見えるのを防ぐ)。傾けない時は変わらない

### カメラ タブ / 画ぶれ

カメラ (やほかのオブジェクト) にランダムなブレを加える。アニメーションはそのままで、ブレを上乗せする。

1. ぶらしたいものを選択して「画ぶれ」を押す。カメラでも、球・ロケータなどほかのオブジェクトでもよい
   (複数選択可。何も選択していなければアクティブなビューのカメラ)
2. 選択したもの 1 つにつき `dfx_cameraShakeN` が 1 つでき、そのチャンネルボックスでブレを調整する
   (複数選択した時は、同じぶれ方にならないよう乱数シードを 1 ずつずらす)
3. 外すときは「画ぶれを外す」(ぶらしているオブジェクトを選択してもよい)。元どおりになる

| オプション | 内容 | 反映 |
| --- | --- | --- |
| カメラの回転のブレ | ON: 向きもぶれる / OFF: 位置だけぶれる (下の表) | すぐ |
| 回転の基準距離 (カメラ以外) | カメラ以外の回転のブレの大きさ。この距離先の点が「強さ」ぶんずれる角度で回る (既定 5。小さいほど大きく回る) | すぐ |
| X (横) の強さ / Y (縦) の強さ | 画面の横・縦方向のブレの大きさ (シーンの単位、既定 0.2)。**キーを打てば、だんだん強く・弱くできる** | すぐ |
| Z (奥行き) の強さ | 奥行き方向 (カメラの前後) のブレの大きさ (既定 0 = ぶれない)。キーを打てる | すぐ |
| 間隔 (フレーム) | 何フレームごとにブレの向きが変わるか (既定 2)。キーを打てば、その時々の間隔で作る | 「画ぶれを更新」 |
| 間隔のばらつき | 0 で一定。0.5 なら 間隔 × 0.5〜1.5 の間でばらつく | 「画ぶれを更新」 |
| 強さのばらつき | 0 で毎回「強さ」いっぱい。0.5 なら 強さ × 0.5〜1 の間でばらつく | 「画ぶれを更新」 |
| 動き方 | なめらか (手持ちカメラのような揺れ) / 直線 / カクカク (衝撃など、キーのフレームでぱっと動く) | 「画ぶれを更新」 |
| 乱数シード | 変えるとブレ方が変わる | 「画ぶれを更新」 |

強さと間隔は基準の値で、実際のブレはそこからランダムに決まる (向きもほぼ毎回反対になる)。

| カメラ | 回転のブレ ON | 回転のブレ OFF |
| --- | --- | --- |
| 注視点のあるカメラ (Camera and Aim など) | カメラの位置に加えて、注視点にも別のブレを入れる (向きがぶれる) | 注視点にもカメラと同じブレを入れる (向きは変わらず平行移動) |
| 注視点のないカメラ | カメラの位置に加えて、回転 X / Y にもブレを入れる | カメラの位置だけぶれる |
| カメラ以外 (球・ロケータなど) | 注視点のないカメラと同じ (位置と回転 X / Y) | 位置だけぶれる |

- ブレの向きは画面の横・縦 (カメラの X / Y 軸) と奥行き (Z 軸、カメラの前後)。カメラがどちらを向いていても、
  画面上で横・縦・前後にぶれる。カメラ以外は、そのオブジェクトの X / Y / Z 軸の向きにぶれる (回転させてあれば、その向き)
- Z のブレは横・縦とは別の乱数で動く。注視点のあるカメラは、回転のブレ OFF なら注視点も同じだけ前後に動き (向きは変わらない)、
  ON ならカメラだけが前後に動く (注視点の方向へ近づく・離れるだけなので、向きは変わらない)
- Z を追加する前に作った画ぶれは、「画ぶれを更新」で Z (奥行き) の強さが使えるようになる (横・縦のぶれ方は変わらない)
- 注視点のないカメラの回転のブレは、「中心までの距離」(カメラの centerOfInterest) 先の点を
  強さぶんずらした時の角度 (注視点のあるカメラと同じ感覚になる)
- ブレはカメラ・注視点の translate / rotate ではなく、足し算用のチャンネル (rotatePivotTranslate・rotateAxis)
  に入れるので、カメラに打ってあるキーはそのまま使える。もともと入っていた値にも足すだけ
- 乱数のキーは、作成・更新した時点のタイムスライダーの範囲に打つ。範囲を変えたら「画ぶれを更新」
- 1 つのオブジェクトに付けられる画ぶれは 1 つ。1 つでも付けられないもの (チャンネルがロックされている等) があれば、何も作らない
- 「画ぶれ」のルートだけを選択して押しても、ルート自身はぶらさない
- **ベイク**すると (ぶらしているオブジェクトを選択してもよい)、ブレ込みの動きをカメラ (と注視点) の translate / rotate の毎フレームのキーにして、
  ブレ用チャンネルは元に戻す (FBX にそのまま持っていける)。注視点のあるカメラは lookAt を残し、注視点の translate にキーを打つ
- 「ダミーエフェクトを全削除」でもカメラは元どおりになる。ルートを Delete キーで消すとブレ用チャンネルに
  その時の値が残るので、「画ぶれを外す」を使う

### カメラ タブ / 手ブレ

手持ちカメラのような、ゆっくりふらふらした揺れを加える。画ぶれと同じ仕組み・同じ使い方
(選択したオブジェクトに付ける・カメラ以外にも付けられる・キーはそのまま上乗せ・「手ブレを外す」で元どおり・ベイク対応)。

画ぶれとの違い:

- 画ぶれは乱数のキーで向きがほぼ毎回反対になる (ぶるぶる・ガクガク)。手ブレはなめらかな乱数の波 (noise) で、ゆっくり漂うように揺れる
- キーを打たないので、**パラメータはすべてすぐ反映**される。タイムスライダーの範囲にも関係ない
- 傾き (画面のロール) も揺れる

| オプション | 内容 |
| --- | --- |
| カメラの回転のブレ | ON: 向きと傾きも揺れる / OFF: 位置だけ揺れる (画ぶれと同じ。注視点の扱いも同じ) |
| X (横) の強さ / Y (縦) の強さ | 画面の横・縦方向の揺れの大きさ (シーンの単位、既定 0.05)。キーを打てばだんだん強く・弱くできる |
| Z (奥行き) の強さ | 奥行き方向 (カメラの前後) の揺れの大きさ (既定 0 = 揺れない)。注視点の扱いは画ぶれの Z と同じ。前に作った手ブレは「手ブレを更新」で使えるようになる (今までの揺れ方は変わらない) |
| 傾き (Z 回転) の強さ (度) | 画面の傾きの揺れの大きさ (既定 0.5°)。回転のブレ ON の時だけ |
| 揺れの周期 (フレーム) | ゆっくりした揺れのだいたいの周期 (既定 24)。小さいほど速く揺れる |
| 細かい揺れ | ゆっくりした揺れに重ねる、3 倍くらい速い細かい揺れの割合 (既定 0.5。0 でなめらか) |
| 回転の基準距離 (カメラ以外) | 画ぶれと同じ |
| 乱数シード | 変えると揺れ方が変わる (複数選択した時は 1 ずつずらす) |

- 傾きは、注視点のないカメラ・オブジェクトは回転 (rotateAxis) Z、注視点のあるカメラは lookAt の twist に入れる
  (ベイクすると、それぞれ rotate / twist のキーになる)
- 1 つのオブジェクトに付けられるのは、画ぶれか手ブレのどちらか 1 つ
- 「手ブレを更新」はふだん使わなくてよい (パラメータはすぐ反映されるため。古いバージョンで作った手ブレを今の仕組みにする時など)
- 周期にキーを打つと、変わっている間は揺れる速さが少し不自然になることがある

### カメラ タブ / パラメータの保存と読み込み

集中線・スピードライン・画ぶれ・手ブレとも、追尾弾と同じようにパラメータを保存・読み込みできる。

- **〜のパラメータを保存**: 1 つ選択して押すと、ルートのアトリビュートの値を `.json` に保存する
- **〜のパラメータを読み込み**: 選択して (複数可) 押し、`.json` を選ぶと、その値を設定して作り直す。
  Ctrl+Z 1 回で読み込み前に戻せる
- 保存されるのはルートのパラメータだけ。中央の円・四角の位置・回転・大きさ (キー) は含まず、読み込んでもそのまま
- 既定の保存先は「シーン → 環境設定」で変えられる。空欄なら `マイドキュメント/maya/DummyEffectMaker/presets/focus_lines/`
  (スピードラインは `.../speed_lines/`、画ぶれは `.../camera_shake/`、手ブレは `.../hand_shake/`)
- 種類の違うプリセットは読み込めない。キーを打ってあるアトリビュート (画ぶれの強さなど) は変更しない

### エネルギー弾 タブ / エネルギー弾

ロケータごとに 1 つの球が、スケール 0 から出現し、ガタガタぶれながら目標のロケータへ飛んでいく。

1. 「エネルギー弾」を押す (選択は不要)。「個数」分の組ができる
2. 発射位置のロケータ (`dfx_energyN_start_01` …) と目標のロケータ (`_target_01` …、赤) を好きな位置に動かす
3. 球ごとのタイミングは**発射位置のロケータ**のチャンネルボックスで、見た目は**ルート**のチャンネルボックスで調整する

```
dfx_energy1                 ← 全体のパラメータ (半径・色・ジッターなど)
  dfx_energy1_start_01      ← 発射位置。出現開始 / 発射 / 着弾フレーム
    dfx_energy1_ball_01     ← 球 (ロケータの子)
  dfx_energy1_target_01     ← 目標
  ...
```

球の動き: 出現開始フレームから「出現フレーム数」かけてスケール 0 → 半径 (ease-out) → ガタガタぶれながら待機 →
発射フレームから着弾フレームまでかけて目標へ飛ぶ → 着弾後は消える (または目標に残る)

| パラメータ (ルート) | 内容 | 反映 |
| --- | --- | --- |
| 球の半径 / 色 | | すぐ |
| ジッターの強さ | ぶれる幅 (半径に対する割合)。0 でぶれない | すぐ |
| ジッターの速さ | 大きいほど細かくガタガタする | すぐ |
| 出現フレーム数 | スケール 0 から元の大きさになるまでのフレーム数 | すぐ |
| 飛び方 | 加速 (だんだん速く) / 等速 | すぐ |
| 着弾後 | 消える / 目標に残る | すぐ |
| 個数 | 「エネルギー弾を更新」で反映。既存のロケータ (位置・タイミング) はそのまま、増えた分は追加、減った分は後ろから削除 | 更新 |
| 出現開始 / 出現後の待機 / 飛ぶフレーム数 / ずらし / 間隔 / 目標までの距離 | 作成時と、更新で球を増やすときの初期値。「タイミングを全部の球に適用」を ON にして更新すると全部の球のタイミングをこの値で設定し直す | 更新 |

| アトリビュート (発射位置のロケータ) | 内容 |
| --- | --- |
| 出現開始フレーム | 球が出現し始めるフレーム |
| 発射フレーム / 着弾フレーム | このフレームからこのフレームまでかけて目標へ飛ぶ |

- 動きはエクスプレッションで計算しているので、ロケータを動かしても値を変えてもすぐ反映される
- 「ベイク」で毎フレームのキーにできる (FBX 用)。「ダミーエフェクトを全削除」でロケータごと消える

### 衝撃波 タブ / 衝撃波

中心のロケータから、端のロケータの距離まで、ドーナツ (輪) がブワッと広がる。

1. 「衝撃波」を押す。選択は不要
2. ルート `dfx_shockwaveN` の子に、中心 `_center` と端 `_edge` (赤) のロケータができ、輪は中心のロケータの子になる
3. ロケータを動かして、位置と広がる大きさ (中心〜端の距離) を決める。
   **中心のロケータを回転させると輪の向きが変わる** (輪は中心のロケータの XZ 面に広がる。X 90° で縦の輪)

```
dfx_shockwave1            ← パラメータ (チャンネルボックス)
  dfx_shockwave1_center   ← 中心
    dfx_shockwave1_ring_01
  dfx_shockwave1_edge     ← 端 (ここまで広がる)
```

| オプション | 内容 | 反映 |
| --- | --- | --- |
| 端までの距離 | 作成時の端のロケータの位置 (中心から X 方向)。作成後はロケータを直接動かす | 作成時のみ |
| 開始フレーム | 1 つ目の輪が出るフレーム | すぐ |
| 輪の数 / 輪の間隔 (フレーム) | 続けて出す輪の数と、その間隔 | 数は「衝撃波を更新」、間隔はすぐ |
| 初速 | 出た瞬間の広がる速さ (1 フレームに広がる距離、既定 2) | すぐ |
| 減衰率 | 毎フレーム、速さがこの割合ずつ遅くなる (既定 0.15。0 で一定の速さ、大きいほど急に止まる) | すぐ |
| ドーナツの太さ | 輪の太さ (チューブの半径、既定 0.4) | すぐ |
| 終わりの太さ (割合) | 端まで広がった時の太さ (ドーナツの太さに対する割合、既定 0.3)。広がるにつれてこの太さになる | すぐ |
| 平たさ | 輪の縦の太さの倍率 (1 で丸、小さいほど平たい帯) | すぐ |
| 消えるフレーム数 | 端に届いてから、細くなって消えるまでのフレーム数 (既定 6) | すぐ |
| 色 / 不透明度 | 輪の色と不透明度 (ライティングの影響を受けない) | すぐ |
| 分割数 | 輪の周りの分割数 (太さ方向はこの 1/4) | 「衝撃波を更新」 |

- 広がる速さ = 初速 × (1 − 減衰率)^経過フレーム。端の距離に届いたら止まり、「消えるフレーム数」かけて細くなって消える
- 作成・更新時のログに「端まで何フレームで広がるか」が出る。減衰が強すぎて端まで届かない時は、
  届く所 (最大の半径の 99%) まで広がって消え、ログで知らせる
- 太さは半径と別に変えられるよう、輪は「太さ 0 のトーラス」に「太い トーラス」をブレンドシェイプでつないで作っている
  (ウェイト = 太さ / 半径)。ウェイトは 0〜1 なので、広がり始めの小さいうちはチューブが半径より太くならない (丸い塊から輪になる)
- **ベイク**すると、大きさ・表示とブレンドシェイプのウェイトが毎フレームのキーになる。ブレンドシェイプは残るので、FBX でもそのまま使える
- パラメータの保存・読み込み (既定の保存先は `.../presets/shockwave/`)、「ダミーエフェクトを全削除」にも対応

### お化けブラー タブ

既に動いている (アニメーションの付いた) オブジェクトに、速さを表すブラーを付ける。
アニメの「お化け」のような表現で、3 種類あり、組み合わせてもよい。どれも元のアニメーションは変えない。

1. 動いているオブジェクト (球・剣のグループなど。複数可) を選択する
2. 「残像」「スミア (引き伸ばし)」「軌跡」のどれかを押す。オブジェクト 1 つにつき 1 つ、ルートができる
3. 止まっている時は出ず、速く動いた時だけ出る (過去のフレームの位置を読んで作る)

```
dfx_afterimage1        ← 残像のパラメータ (チャンネルボックス)
dfx_smear1             ← スミアのパラメータ (ラティスは非表示)
dfx_trail1             ← 軌跡のパラメータ
  dfx_trail1_a / _b    ← 帯の両端 (オブジェクトに付いて動くロケータ)
```

#### 残像

少し前の位置に、オブジェクトのコピーを何体も並べる。後ろほど薄く (小さく) なる。

| オプション | 内容 | 反映 |
| --- | --- | --- |
| 残像の数 | 並べるコピーの数 (既定 5) | 「お化けブラーを更新」 |
| 間隔 (フレーム) | 1 体ごとに何フレーム前の位置にするか (小数も可、既定 1) | すぐ |
| 先頭 / 最後の不透明度 | 一番前と一番後ろの残像の不透明度 (間は直線で変わる) | すぐ |
| 先頭 / 最後の色 | 一番前と一番後ろの残像の色 (ライティングの影響を受けない) | すぐ |
| 最後の大きさ (割合) | 一番後ろの残像の大きさ (先頭は 1)。ピボットを中心に縮む | すぐ |
| 出始める速さ / くっきり出る速さ | 1 フレームに動く距離がこれ以下なら出さない / これ以上で不透明度どおり (間は徐々に濃く) | すぐ |

- オブジェクトの中のメッシュ全部をコピーする (グループならメッシュごと)。形は元のメッシュとつながっているので、モデルを直せば残像も変わる
- スキンで変形するメッシュは、今の形のまま前の位置に出る (ポーズは過去にならない)
- 不透明度などにキーを打てば、だんだん強く・弱くできる

#### スミア (引き伸ばし)

オブジェクト自体を、進行方向の後ろへ餅のように引き伸ばす。後ろ側ほど少し前のフレームの位置に残るので、
曲がって動けば曲がって伸びる。オブジェクトを囲むラティス (非表示) で変形する。

| オプション | 内容 | 反映 |
| --- | --- | --- |
| 伸びるフレーム数 | 一番後ろが、何フレーム前の位置まで残るか (既定 3) | すぐ |
| 強さ | 伸びるフレーム数に掛ける倍率。キーを打てば一瞬だけ伸ばすこともできる | すぐ |
| 伸び始める位置 | 進行方向の前 (0) 〜 後ろ (1) のどこから伸び始めるか (既定 0.3)。前の部分は形が変わらない | すぐ |
| カーブ | 伸び方の偏り。1 で一様、大きいほど後ろの端だけが伸びる | すぐ |
| 最大の伸び (大きさの倍率) | 伸びる距離の上限 (オブジェクトの大きさ × この値)。瞬間移動した時に伸びすぎないように | すぐ |
| なめらかさ | 伸びるフレーム数の間を何回に分けて位置を読むか (既定 6)。曲がって動く時は多めに | すぐ |
| ラティスの分割数 | 多いほど細かく曲がる (重くなる) | 「お化けブラーを更新」 |

- 1 つのオブジェクトに付けられるスミアは 1 つまで。ルート (`dfx_smearN`) を削除するとラティスも外れて元の形に戻る
- 回るだけ (移動しない) の時は伸びない
- オブジェクトの形や大きさを変えたら「お化けブラーを更新」でラティスを作り直す

#### 軌跡

通った跡に、先が細くなる帯 (またはチューブ) を残す。

| オプション | 内容 | 反映 |
| --- | --- | --- |
| 形 | 帯: 2 点 (`_a` / `_b`) の通った跡を結ぶ / チューブ: 2 点の中点の通った跡を囲む (直径 = 2 点の距離) | 「お化けブラーを更新」 |
| 長さ (フレーム) | 何フレーム前の位置までの跡を残すか (既定 8) | すぐ |
| 分割数 / チューブの周りの分割数 | 長さ方向と、チューブの周りの分割数 | 「お化けブラーを更新」 |
| 根元 / 先の太さ (割合) | 根元 (オブジェクト側) と先の太さ (既定 1 → 0) | すぐ |
| 根元 / 先の不透明度、根元 / 先の色 | 根元から先へ、U 方向のランプで変わる | すぐ |

- 帯の両端 `_a` / `_b` はルートの子のロケータで、オブジェクトに付いて動く (作成時はオブジェクトの上下の端)。
  剣なら根元と先に動かすと、刃の通った跡になる。「お化けブラーを更新」しても位置はそのまま
- メッシュの無いもの (ロケータ・ジョイントなど) にも付けられる (幅 1 の帯)
- 帯は行ごとのジョイントにスキンしてあり、エクスプレッションがジョイントを毎フレーム置く

#### お化けブラー共通

- 「お化けブラーを更新」「パラメータを保存 / 読み込み」は、ルートか、付けたオブジェクトを選んで使う
  (付けたオブジェクトを選ぶと、付いている物全部が対象)。プリセットは同じ種類にだけ読み込める
  (既定の保存先は `.../presets/afterimage/` `smear/` `trail/`)
- 付けたオブジェクトの名前や親を変えても付いて動く
- **ベイク** (付けたオブジェクトを選んでもよい):
  - 残像: コピーの移動・回転・大きさ・表示と、マテリアルの色・透明度のキーになる。形は元のメッシュから切り離す
  - 軌跡: ジョイントの動きのキーになり、スキンは残る。FBX でもそのまま使える
  - スミア: ラティスの点のキーになる (Maya 内ではそのまま動く)。ラティスは FBX では書き出せないので、
    他のツールへは Alembic (ジオメトリキャッシュ) で持っていく
- 「ダミーエフェクトを全削除」で消える (スミアのラティスも外れる)。作成は 1 回のアンドゥで戻る

### 天候 タブ

風・雨・雪・土煙・火花・霧・地霧を、アニメ調で作る。それぞれ 2 つの作り方があり、
「おすすめ」は近景向け、もう一方は遠景や広い範囲向け。組み合わせて使える (近くは粒、遠くは筒など)。

| 種類 | おすすめ | もう一つの作り方 |
| --- | --- | --- |
| 雨 | **線と跳ね**: 落ちる向きに伸びた線が降り、地面で輪が跳ねる | **遠景の筒**: カメラを囲む筒 (何重か) に雨の筋のテクスチャを流す |
| 雪 | **粒**: カメラを向く白い丸が揺れながら降る | **遠景の筒**: 同じ作りで雪の粒をゆっくり流す |
| 土煙 | **スプライト**: 煙の絵 (2 色・ふちはくっきり) の板が広がって消える | **もこもこ**: 丸を集めた立体の煙 (中は明るく、ふちは影の色) |
| 火花 | **線**: 進む向きに伸びた線が重力で落ち、地面で跳ねる | **尾を引く**: 通った跡を細い帯で引く |
| 霧 | **霧の板**: カメラを向く大きな霧の板を風で流す | **遠景の重ね板**: カメラの前に薄い板を何枚も重ね、遠くほど霧の色に (空気遠近) |
| 地霧 | **重ね板**: 地面と平行な板を高さ違いで重ね、模様を流す (上ほど薄い) | **這う霧**: 平たい霧の板が地面すれすれを漂う |
| 稲妻 | **実写**: 細かく枝分かれした細い線 (まわりに青白い光の帯) | **アニメ**: 大きくジグザグに折れた太い円柱 (真ん中に白い芯。上下から見てもパースが付く) |

作り方の共通点:

- nParticle (シミュレーション) は使わず、粒の位置を「出たフレーム・初速・重力・風」から計算する。
  どのフレームに飛んでも同じ結果で、キャッシュもいらない
- 雨・雪・霧・地霧は **範囲の箱** (`_area`) の中に出る。箱を動かす・拡大縮小して範囲を決める
  (箱の底が地面)。箱は原点に作る。「カメラに付いて動く」を ON にすると、箱をカメラの真下に置き、
  カメラの横移動に付いていく (ビューのカメラ persp だと、ビューを回すたびに箱も動く)。
  粒は箱の上の面のランダムな位置から出て、落ちる速さ × 経過フレーム (と風) だけ下へ進む。
  横は箱の中で回り込む (風で流れて箱から出た分は、反対側から出る)。
  フレームを変えずに箱やカメラを動かしても、すぐ付いてくる
- 土煙・火花は **出る場所** (`_emitter`、黄色のロケータ) から出る。オブジェクト (車輪・足・剣など) を
  選んで作ると、出る場所がそれに付いて動く
- 板はカメラを向く。カメラを選んで作るとそのカメラ、選ばなければ今のビューのカメラ
- 量・不透明度・速さなどほとんどのパラメータはすぐ反映され、キーを打てる
  (例: 雨の「量」にキーを打って降り始め・止みを作る)。「(更新)」の付いた数などは「天候を更新」
- テクスチャ (雨の筋・雪の粒・煙・霧の模様) は、作成時にプロジェクトの `sourceimages/dfx_weather/` に PNG を作る
- **自分の絵を使う**: 土煙 (スプライト)・雨 / 雪 (遠景の筒)・霧 (霧の板)・地霧 (重ね板 / 這う霧) は、
  オプションの「テクスチャのファイル」(「参照...」で選べる) に自分の絵を指定できる。空欄なら既定の絵。
  作成後はルートの `dfx_texture` (アトリビュート エディタの Extra Attributes) を書き換えて「天候を更新」。
  - 透明度付きの PNG などを使い、白っぽく描くと「色」で色を付けられる (絵の色 × 色)
  - 遠景の筒・地霧 (重ね板) の絵は繰り返して貼るので、端がつながる絵にする。
    遠景の筒は絵の縦横比に合わせて繰り返す (「模様の大きさ」が絵 1 枚の幅)
  - 既定の絵 (`dfx_puff_v1.png` など) を描き直してもよい (同じ名前のまま。作り直さなくても変わる)

#### 風

`dfx_windN` (矢印) の向き (+X) が風向き。回転させて変える。シーンの天候 (霧の遠景の重ね板以外) は、
この風で流される (雨は傾き、雪・霧は流れ、土煙はなびく)。各天候の「風の影響」で流され方を変えられる。

| オプション | 内容 |
| --- | --- |
| 強さ | 1 フレームに流れる距離 (既定 0.15)。キーを打てる |
| 突風の強さ | 突風の時に強さがこの倍率だけ増える (0 で突風なし)。キーを打てる |
| 突風の間隔 / 長さ / ばらつき | 突風が来る間隔と、続く長さ、そのばらつき |
| 乱れ | 風向きのゆらぎ (1 で ±45°) と上下のゆらぎ |

- 風に流された距離は、作成時と「風を更新」の時に、タイムスライダーの範囲 (と前 400 / 後 60 フレーム)
  の毎フレームの値を計算して風に持たせる。**強さ・突風・矢印の向きを変えたり、タイムスライダーの範囲を
  広げたりしたら「風を更新」**
- 風を作ると、風につながっていない天候をつなぐ。風がある時に天候を作ると、その風 (風を選んでいればそれ) につなぐ

#### 細い煙 (たばこ・線香)

出る場所 (`_emitter`) から、細い煙の筋が何本か上がる。根元は「まっすぐ上がるフレーム数」の間まっすぐで、
その後は上ほど大きく揺れて曲がり、筋どうしが絡み合いながら広がって、薄くなって消える。風にも流される。
オブジェクト (たばこ・線香など) を選んで作ると、出る場所がそれに付いて動く。

- 重いシミュレーションは使わない。筋の点を「出てから何フレームたった煙か」として、出た時刻から位置を直接計算する
  (どのフレームにもすぐ飛べる)。揺れはなめらかな乱数なので、同じ形を繰り返さない
- 帯はカメラを向く帯 (火花の尾と同じジョイントの帯)。煙の筋の絵を根元 → 先に貼る (幅の真ん中が濃く、先ほど薄い)。
  見た目は実写 (やわらかく消える) とアニメ (くっきりした濃さの段) から選べる。自分の絵も使える
- 揺れの大きさ・長さ (細かさ)・速さ、まっすぐ上がる長さ、根元と先の太さ、上がる速さ・消えるまでのフレーム数はすぐ反映。
  筋の数・点の数・見た目・絵は「天候を更新」。不透明度にキーを打てば、煙を出し始め・止めにできる

#### 稲妻

雲の点 (`_top`) から落ちる所 (`_ground`) へ、何回か落ちる。作成時にオブジェクトを選んでいればそこへ落ち (雲の点はその真上)、
カメラを選んでいれば帯はそのカメラを向く。回ごとに形と落ちる所が変わる (「落ちる所のばらつき」)。

- 1 回の稲妻は、雲から地面へ「伸びるフレーム数」で伸びてから、「光るフレーム数」だけちらつきながら光って消える
- 落ちるのは「開始フレーム」から「間隔」ごと (ばらつきあり) に「落ちる回数」だけ
- 帯は本筋と枝の点ごとのジョイントにスキンしてある (火花の尾と同じ。ベイクすれば FBX でも使える)。
  2 本目の帯は、実写では外側のぼんやりした光、アニメでは真ん中の白い芯
- **アニメは円柱 (チューブ)**: 真上・真下から見ても太さがあり、パースが付く (分割数は「円柱の分割数」)。
  芯は円柱の表面のすぐ前に置いた、カメラを向く帯なので、どこから見ても真ん中に見える。
  ジグザグの辺は中で 4 つに分けてあり、折れ目で円柱がつぶれない
- 「終端のギザギザ」で、ジグザグの振れ幅を終端 (地面) に向かって小さくできる (雲の側に対する割合。1 で同じ、
  0 で終端はまっすぐ。アニメの既定は 0.3)。放電でも使える (発生 → 終端に向かって小さくなる)
- 点の数・枝の数・2 本目の帯の太さ (アニメは円柱の分割数も) は「天候を更新」で反映。ほかはすぐ反映 (キーも打てる)

#### 放電 (稲妻で攻撃する)

発生 (`_start`) と終端 (`_end`) の 2 つのロケータの間に、稲妻が**流れ続ける** (実写・アニメ)。両方のロケータにキーを打ってよい。
「形が変わる間隔」ごとに形が変わってバチバチし、「開始フレーム」〜「終わりのフレーム」の間ずっと流れる。

- **終端の側がコリジョンに当たると小爆発**する (爆発と同じ部品・パラメータ: 閃光・輪・火の玉・煙・火花)。
  「爆発の間隔」ごとに、発生と終端の真ん中から終端の少し先 (「当たりの届く長さ」) までの線がコリジョンに当たるか調べ、
  当たった所で爆発する。終端を地面に沿って動かすと、地面をえぐっていくように爆発が続く
- ロケータ・コリジョンを動かしたら「天候を更新」で爆発の場所を計算し直す (稲妻の形はすぐ付いてくる)
- コリジョンが無ければ、稲妻だけ流れる。書き出し (Unreal 用) には、当たった所も書く

#### 天候の共通の操作

- 「天候を更新」「天候のパラメータを保存 / 読み込み」は、ルートか、その中の物 (範囲の箱など) を選んで使う。
  プリセットは同じ種類にだけ読み込める (風も保存できる)
- **ベイク**: 粒の動き (移動・回転・大きさ・表示)、火花の尾のジョイント (スキンは残る)、テクスチャの濃さ・流れ
  (file / place2dTexture / ramp) がキーになる。粒と帯は FBX でもそのまま使える
  (テクスチャの流れ・濃さのアニメーションは FBX では伝わらないことが多い)
- 半透明のマテリアルは、ビューポート (Viewport 2.0)・Hardware 2.0・Arnold で正しく重なるように作っている
  (色はそのまま、不透明度は透明度で)。Maya Software でレンダリングすると、半透明の所が明るく (白っぽく) 出る
- 粒が多いと再生が重くなる (雨 400 粒で 1 フレーム約 30 ms)。遠くは「遠景の筒」に任せて粒を減らすとよい
- 地霧 (重ね板) はカメラが低いと板の重なりが見える。その時は「這う霧」を手前に
- **ビューポートで黒く見える時**: 土煙・遠景の筒・霧の板・地霧 (とお化けブラーの軌跡) は、色や透明度を
  テクスチャで作っているので、ビューポートのテクスチャ表示が OFF だと真っ黒・不透明に表示される。
  ビューポートで **6 キー** (シェーディング → ハードウェアテクスチャリング) を押す。
  作成時にテクスチャ表示が OFF のビューポートがあれば、ログで知らせる
- **霧などがビューポートで消える時**: ハードウエアレンダリングの透明度のアルゴリズムが「アルファ カット」だと、
  半透明の部分 (霧・地霧・雨・遠景の筒・残像・軌跡・衝撃波) が消える。Viewport 2.0 の設定
  (レンダラ → Viewport 2.0 □) かレンダー設定で「オブジェクトのソート」(既定。重なりが多い時は「深度ピーリング」) にする。
  作成時にアルファ カットなら、ログで知らせる。Arnold はこの設定に関係なく正しく描く
- 霧の板・這う霧は、板ごとに濃さが違うので、板は別々のメッシュ (インスタンスではない) にしている
  (インスタンスごとにマテリアルを変えると Arnold で表示されないため)

### 爆発 タブ

追尾弾・バルカン砲・エネルギー弾が、**コリジョン**に指定したモデルにぶつかった所で爆発する。

1. ぶつける相手のモデルを選んで「**コリジョンに指定**」(複数可。グループなら中のメッシュ全部)。
   ローポリで自由にモデリングしてよく、**移動・回転・拡大縮小のアニメーション**にも対応する
   (骨やデフォーマで変形するメッシュは、今の形で判定する)
2. 弾 (ルートか、その中の弾) を選んで「**爆発**」。弾の通り道を 1 フレームを細かく分けてたどり、
   最初にコリジョンに当たった所で爆発する。**当たった弾は消える**
3. 弾・コリジョンを動かした、アニメーションを変えた、タイムスライダーの範囲を広げた時は
   「**爆発を更新**」(爆発か弾を選ぶ) で当たりを計算し直す

```
dfx_explosion1     ← パラメータ (チャンネルボックス)。弾のルートとつながる
  _flashes         閃光 (カメラを向く丸)
  _rings           衝撃波の輪 (当たった面に沿って広がる)
  _fire / _smoke   火の玉と煙 (もこもこの塊。アニメ調の 2 色)
  _sparks          火花 (重力で落ちる線)
```

| オプション | 内容 | 反映 |
| --- | --- | --- |
| 大きさ | 爆発全体の大きさの倍率 | すぐ |
| 当たった弾を消す | OFF にすると、当たっても弾は飛び続ける (爆発だけ出る) | すぐ |
| 当たり判定の細かさ | 1 フレームを何回に分けて調べるか (既定 4)。速い弾や薄いモデルは多めに | 「爆発を更新」 |
| 閃光・衝撃波 | 大きさ・フレーム数・色 (大きさ 0 で出さない) | すぐ |
| 火の玉・煙 | 数・大きさ・広がり・フレーム数・色・影の色 (煙は上がる速さも) | 数は「爆発を更新」、ほかはすぐ |
| 火花 | 数・速さ・フレーム数・重力・色 | 数は「爆発を更新」、ほかはすぐ |
| 不透明度 / シード | 全体の不透明度と、ばらつきの種 | すぐ |

- 爆発は当たった面の向きに広がる (閃光と火の玉は面の手前、輪は面に沿って広がる)。
  煙は少し遅れて出て、ワールドの上へ上がる
- 当たったフレームと位置・面の向きは、ルートの `dfxHits` に入っている (8 個ずつ: フレーム、弾の番号、位置、向き)
- 当たった弾は lodVisibility で隠す (弾のアニメーションには手を加えない)。「爆発を外す」で爆発を消すと元に戻る。
  弾を「〜を更新」で作り直した時は、「爆発を更新」も押す
- 「コリジョンを解除」で外す (何も選ばなければ全部)。コリジョンのモデル自体は「全削除」でも消えない
- **ベイク**: 爆発の動き・表示がキーになる。弾も一緒にベイクすると、当たって消えるのは弾の visibility のキーにまとまる (FBX 用)
- 再読み込み・作成・更新・外す・全削除・プリセット・1 回のアンドゥに対応

### 爆発 タブ / 爆発 (単体)

コリジョンも弾も無しで、**置いた所 (爆心のロケータ `_center`) で起きる爆発**。部品と動き・パラメータは「爆発」と同じ
(閃光・衝撃波の輪・火の玉・煙・火花)。オブジェクトを選んでいればその位置に置き、カメラを選んでいれば閃光はそのカメラを向く。

- 当たった所・面の向きの代わりに、爆心のロケータの位置と上 (Y) の向きを使う (輪はその面に沿って広がり、火の玉はその向きへ)
- 起きるフレームは「開始フレーム」。ロケータを動かす・回す・キーを打つと、作り直さなくても付いてくる
- 数 (火の玉・煙・火花) を変えたら「爆発を更新」。ほかはすぐ反映。ベイク・書き出し・アトリビュートエディタにも対応
- 大きな爆発 (キノコ雲) は「核爆発」

### 爆発 タブ / 核爆発

弾が無くても、置いた所で起きる**規模の大きな爆発 (キノコ雲)**。「**核爆発**」を押すと、爆心のロケータ (`_center`) とルートができる
(オブジェクトを選んでいれば、その位置に置く。カメラを選んでいれば閃光はそのカメラを向く)。

- ロケータを動かして場所を、回して雲が上がる向き (ロケータの上 = Y) を決める。キーを打ってもよい
- 起きるフレームは「開始フレーム」、全体の進み方は「速さ (時間の倍率)」(0.5 でスローモーション)

時間の順に、次の部品が出る:

```
dfx_nuke1        ← パラメータ (チャンネルボックス)
  _center        爆心 (動かす・回してよい)
  _flash         閃光 (カメラを向く丸。すぐ消える)
  _shock         地面を走る衝撃波の輪 (爆心の水平な面に広がって薄れる)
  _dome          衝撃波のドーム (半球。速く広がって薄れる)
  _fireball      火の玉 (かさと一緒に上がり、小さくなって消える)
  _stem          キノコ雲の柱 (根元ほど太い)
  _cap           キノコ雲のかさ (外側から下へ巻き込みながら広がる)
  _base          根元に広がる土煙
```

| オプション | 内容 | 反映 |
| --- | --- | --- |
| 大きさ | 全体の大きさ (火の玉の半径くらい)。ほかの大きさはこの倍率 | すぐ |
| キノコ雲の高さ・上がるフレーム数 | かさが最後に届く高さ (大きさの倍率) と、上がり切るまでのおおよその時間 | すぐ |
| 消えるまでのフレーム数 | 雲が消えるまで (最後の 1/4 で薄れる) | すぐ |
| 火から煙になるフレーム数 | 雲 (柱・かさ・土煙) の色が、火の色から煙の色に変わるまで | すぐ |
| 閃光・衝撃波・ドーム・火の玉 | 大きさ・フレーム数・色 (大きさ・濃さ 0 で出さない) | すぐ |
| 柱・かさ・根元の煙 | 数・太さ / 広がり・大きさ、かさの巻き込みの速さ、煙の回転 | 数は「核爆発を更新」、ほかはすぐ |
| 色 | 火の色・火の影の色・煙の色・煙の影の色 (アニメ調の 2 色) | すぐ |

- 雲の色と薄れ方、衝撃波・ドームの濃さはマテリアルをエクスプレッションで動かしている (ベイクするとキーになる)
- 書き出し (Unreal 用) では、種類 `nuke`・パラメータ・爆心の動きを書く (Niagara で作り直す時の目安)
- 計算は `motion.py` の `nuke_*` (Blender 版も同じ式)。作成・更新・プリセット・ベイク・全削除・1 回のアンドゥに対応

### 布 タブ / 波打つ布

人形劇で海などを表す、透ける布 (オーガンジー・シフォン) を何枚も重ねて波打たせる表現。

```
dfx_cloth1           ← パラメータ (チャンネルボックス)
  _stage             舞台 (ロケータ。動かす・回す・拡大縮小すると、布の束がまとめて動く。キーも打てる)
    _layer_01 ...    布 1 枚分 (手前 → 奥へ重なる)
      _cloth_01      布の板 (細かく分けたポリゴン平面)
      _lattice_01    布を波打たせる格子 (ラティス)
```

- 布は格子の点の高さだけを毎フレーム計算するので軽い。波は布の長さの向きに流れ、横にも少しねじれる
- 奥の布ほど「布ごとのずれ」だけ波が遅れ、「重なりの間隔」だけ奥に、「高さの差」だけ高く置く (順にあおったように見える)
- 色は「手前の布の色」→「奥の布の色」。「不透明度」で透け具合。「両端を押さえる」で、人が端を持っているように端を止める
- 枚数・長さ・幅・波の細かさ (格子の分割) は「波打つ布を更新」。ほかはすぐ反映 (キーも打てる)。
  オブジェクトを選んで作ると、その位置に置く。ベイク・書き出し・アトリビュートエディタにも対応

### シーン メニュー / ベイク

作成したエフェクトの動き (弾の移動・向き・大きさ・表示) を毎フレームのキーにベイクする。
FBX に書き出して他のツール (ゲームエンジン、別の DCC など) へ持っていくときに使う。

1. エフェクト (ルート、またはその中のロケータや弾) を選択して、メニューの「シーン → ベイク」を選ぶ
   (オプションを変える時は「シーン → ベイク (オプション)...」)
2. ルートを選択して ファイル → 選択項目の書き出し で FBX を選んで書き出す

| オプション | 内容 |
| --- | --- |
| 対象 | 選択したエフェクト / シーン内のすべてのエフェクト |
| フレーム範囲 | タイムスライダーの範囲 / 指定した範囲 (開始・終了フレーム) |
| 非表示の間はスケール 0 | ON にすると、非表示のフレームはスケールを 0 にする (表示/非表示のキーも残る)。表示のアニメーションを読まないゲームエンジンなど向け。切り替わりはステップキーで、フレームの間で大きさが中途半端にならない |

- モーションパスや大きさの計算ノード、球の履歴は削除され、キーだけで動く状態になる
- ベイク後は「追尾弾を更新」「パラメータを読み込み」はできない。効かなくなったアトリビュートはロックされる
  (色だけはそのまま変えられる)。Ctrl+Z 1 回でベイク前に戻せる
- 弾はインスタンスのまま。FBX でも表示/非表示のキーは残るが、表示のアニメーションを読まないツールもある。
  その場合は「非表示の間はスケール 0」を ON にする

### シーン メニュー / 書き出し (Unreal 用)

ダミーエフェクトを、Unreal Engine (Niagara) で仕上げるための**ショットのファイル (JSON)** に書き出す。
プレビズの見た目ではなく、**タイミング・配置・パラメータ**を書く。

1. 「シーン → 書き出し (Unreal 用)」(オプションで対象・フレーム範囲を選べる)
2. 保存先を選ぶ (既定はプロジェクトの `data/dfx_shots/`)

書くもの:

- エフェクトの種類・パラメータ (と、その定義)
- 動かして決めた物 (ロケータ・範囲の箱・出る場所など) と、カメラ (画ぶれ込み・焦点距離) の毎フレームの位置・向き
- 弾の通り道と表示、爆発の当たった所と面の向き、風の流れ

座標は右手系・Z が上・メートル (Blender と同じ) に直して書く。Unreal への変換や形式の詳細は
[docs/exchange_format.md](docs/exchange_format.md)。書き出しはシーンを変えない。

### シーン メニュー / ダミーエフェクトを全削除

このツール群で作ったノード (グループ、マテリアル、補助ノード) をまとめて削除する。

### シーン メニュー / 環境設定 (プリセットの保存先)

「パラメータを保存 / 読み込み」のダイアログで最初に開くフォルダを決める。小さなウインドウが開き、
入力した時点で保存される (空欄なら種類ごとの既定のフォルダ)。設定は `%APPDATA%/DummyEffectMaker/settings.json` に残る。

## Blender 版

Maya 版と同じパラメータ・同じ計算・同じ書き出しの形式で、Blender (4.2 以降。5.1 で確認) でもダミーエフェクトを作る。
Maya 版の全部のエフェクト (射撃・カメラ・エネルギー弾・衝撃波・お化けブラー・天候・爆発・核爆発) と、
シーンの「エフェクトを更新」「ダミーエフェクトを全削除」「書き出し (Unreal 用)」がある (プリセットの保存・読み込みとベイクは Maya 版だけ)。

### 起動方法

- **アドオンとして入れる (おすすめ)**: 編集 → プリファレンス → アドオン → ∨ →「ディスクからインストール」で
  `scripts/blender_addon.py` を選び、アドオンの設定の「DummyEffectMaker フォルダ」にこのリポジトリの場所を入れる
  (環境変数 `DUMMY_EFFECT_MAKER_PATH` でもよい)。設定の「読み込み直す」で、再起動せずにコードを読み直せる
- **その場で試す**: `scripts/blender_launcher.py` の `REPO_PATH` を書き換えて、テキストエディタで実行

3D ビューの右のサイドバー (N キー) に「**Dummy Effect**」タブが出る。

### 使い方

- タブ → グループごとにボタンが並ぶ (Maya 版のランチャーと同じ)。ボタンで今のオプションのまま実行、歯車でオプションを開いて実行
- 「**選択したエフェクト**」パネル: 選んだエフェクトのパラメータ。すぐ反映の物は変えるとすぐ変わる。
  「(更新)」の付いた物は「エフェクトを更新」で作り直す
- Maya 版と同じ構成: ルート (Empty。パラメータはカスタムプロパティ `dfx_*`) の子に、動かして決める Empty (発射位置・目標・中心・端) と、ツールが作る物
- Empty にキーを打ってよい (バルカン砲は発射した時点の目標の位置を、キーから読む)
- 動きは、フレームが変わるたび (と、パラメータや Empty を動かした時) に Python で計算し直す (Maya 版と同じ関数)。
  表示しない間は大きさ 0 にしている
- 衝撃波の輪は、中心の Empty のローカル **XY 面** に広がる (Maya 版は XZ 面。Blender は Z が上のため)。太さはシェイプキー `thick`
- 書き出しは Maya 版と同じ形式 (Blender は Z が上・メートルなので座標はそのまま)。保存先はオプションの「書き出すファイル」(`//` は .blend と同じフォルダ)

### Maya 版との違い

- **計算は同じ**: 粒の動き (雨・雪・土煙・火花・霧・爆発) は `motion.py` (Maya 版のエクスプレッションと同じ式の Python 版。
  一致は mayapy の検証で確かめている) を、Y が上に直して使う。弾・衝撃波・風・画ぶれの乱数のキーも Maya 版と同じ関数
- **粒は 1 つのメッシュ**: 雨の線・雪・煙・火花・爆発の部品などは、数だけ並べた 1 つのメッシュの頂点を毎フレーム置き直す
  (オブジェクトが何百も並ばない)。隠す粒は 1 点に縮める
- **範囲の箱・出る場所**: 範囲の箱は Empty の立方体 (拡大縮小・回転してよい)。出る場所は矢印の Empty で、矢印 (ローカル Z) が上。
  作成時にオブジェクトを選んでいれば、その子になって付いて動く。「カメラに付いて動く」はコピー位置 (Z 以外) のコンストレイント
- **風**: 矢印 (ルートのローカル +X) を回す・強さや突風にキーを打つと、自動で計算し直す (Maya 版の「風を更新」は念のため)
- **画ぶれ・手ブレ**: Maya の足し算用チャンネルの代わりに **デルタ トランスフォーム** (delta_location / delta_rotation) にブレを入れる
  (カメラのキーはそのまま)。注視点は Track To / Damped Track / Locked Track のターゲット。手ブレの傾きは注視点のないカメラ・オブジェクトだけ。
  回転のブレの基準距離は、カメラは被写界深度の焦点距離 (0 なら 10)。手ブレの波は Blender のノイズ (Maya の noise() と細かな動きは違う)
- **爆発**: コリジョンはメッシュのカスタムプロパティ `dfxCollider` (親を指定すると子のメッシュも)。当たり判定は BVH で、
  弾の通り道をフレームを動かさずに計算する (Maya 版と同じく、動く・回る・拡大縮小するコリジョンに当たる)
- **稲妻**: 雲の点 (円錐の Empty) と落ちる所 (球の Empty)。帯 (アニメは円柱) はジョイントを使わず、1 つのメッシュの頂点を毎フレーム置く
- **核爆発**: 爆心は矢印の Empty で、ローカル Z (上) の向きに雲が上がる。雲 (柱・かさ・根元) は 1 つのメッシュ。
  煙の数を変えたら「エフェクトを更新」
- **エネルギー弾**: 球ごとのタイミングは発射位置の Empty のカスタムプロパティ (キーを打てる)。個数を変えたら「エフェクトを更新」
- **絵 (テクスチャ)**: ツールが作る絵は .blend と同じフォルダの `textures/dfx_weather/` (保存前の .blend ではユーザーのデータフォルダ)
- **集中線・スピードライン**: `_frame` (Empty) がチャイルドオブ コンストレイントでカメラに付き、距離と画面の大きさはドライバー
  (焦点距離・センサー・センサーのフィット・平行投影・解像度を読む) で決まる。ちらつき・伸びて移動は、Maya 版がキーにする値を
  作成・更新の時に計算してしまっておく (線ごとにグラフエディタで直すことはできない)。カメラのシフトは見ない (Maya 版と同じ)
- **霧の板・這う霧**: 板ごとの濃さは頂点の属性 `dfx_alpha` (ソリッド表示では全体の不透明度だけ)。遠景の筒・霧の重ね板は
  コンストレイントでカメラに付く。地霧の四角いふちのぼかしはマテリアルのノードで作る
- **お化けブラー**: 残像は Geometry Nodes で元のオブジェクトの今の形 (モディファイアー・アーマチュア込み) を写す。
  スミアは元のオブジェクトの最後に Lattice モディファイアーを足す (メッシュのデータは変えない。「お化けブラーを外す」で元に戻る。
  Blender の格子は B スプラインなので、Maya 版より少しやわらかく曲がる)。軌跡はジョイントを使わず、頂点を毎フレーム置く。
  コンストレイント・ドライバーなどで動くオブジェクトは、作成・更新の時にフレームを進めて動きを覚える (変えたら「お化けブラーを更新」)

### Blender 版のツールの足し方

`dummy_effect_maker/blender/tools/` に .py を足し、`hosts = ("blender",)` のツールを書く。
パラメータ (`params`) と計算は Maya 版のモジュールから使い回し、組み立て (`build`) と毎フレームの更新 (`update`) を書いて
`_build.register_builder()` で登録する。画面 (ボタン・オプション・パラメータのパネル) は自動でできる。

検証: `blender -b --factory-startup --python tests/blender_verify.py -- <リポジトリのフォルダ>`
(ほかに `tests/blender_verify_lines.py`・`blender_verify_layers.py`・`blender_verify_ghost.py` も同じように動かす)

## 土台 (Maya / Blender / Unreal で共通にする部分)

プレビズを Maya と Blender で作り、Unreal Engine で仕上げる流れのために、ソフトに依存しない部分を分けている。

| 部分 | ファイル | 中身 |
| --- | --- | --- |
| ツールの仕組み | `core/tool.py`, `core/registry.py` | パラメータの定義 (Param)、ツールの登録、実行とアンドゥ |
| ホスト | `core/host.py` | Maya / Blender / スタンドアロンの差分 (アンドゥ、親ウインドウ)。ツールは `hosts` で動くソフトを決める |
| エフェクトの一覧 | `catalog.py` | 種類ごとの名前・パラメータ・すぐ反映か・分類 (新しいエフェクトを足したらここにも 1 行) |
| 受け渡し形式 | `core/exchange.py` | ショットの JSON、座標の変換 (共通の空間・Unreal)、トラック |
| プリセット・設定 | `core/presets.py`, `core/settings.py` | パラメータの保存、環境設定 |
| 計算 | 各 `tools/*.py` の純粋な関数 | 弾の軌道・粒の動き・当たり判定の考え方など (Maya を使わない) |

ここまでは Maya が無くても動く (Blender 5.1 の Python でも読み込めることを確かめている)。
Maya で組み立てる部分 (エクスプレッション・ノード) は各 `tools/*.py` の `run()` と build 関数の中だけにある。
Blender 版は、同じパラメータと計算を使い、組み立てと毎フレームの更新だけを Blender (Python) で行う。
粒の動きの計算は `motion.py` (Maya にも Blender にも依存しない。Maya 版のエクスプレッションと同じ式) にまとめてある。

## ツールの追加方法

`dummy_effect_maker/tools/` に `.py` を作り、`BaseTool` を継承したクラスを書くだけでランチャーにボタンが追加される。

```python
from ..core import BaseTool, Param


class MyTool(BaseTool):
    label = u"マイツール"          # ボタン名 (必須)
    tab = u"ツール"                # 上部のタブ (新しい名前ならタブが増える)
    # menu = u"シーン"            # 指定するとタブではなく上部のメニューに入る
    category = u"射撃"             # タブ内のグループ名
    order = 30                     # 並び順
    params = [Param("count", u"個数", 10, minimum=1)]   # あれば □ ボタンが付く

    def run(self, ctx, **v):
        from maya import cmds      # Maya の import は run() の中で
        ctx.log(u"count = %d" % v["count"])
```

`Param` の型は既定値から推測される (bool / int / float / str)。選択肢は `kind="choice", choices=[...]`、色は `kind="color"` で `(r, g, b)`。
ユーザー向けのエラーは `ToolError("メッセージ")` を raise するとダイアログで表示される。
